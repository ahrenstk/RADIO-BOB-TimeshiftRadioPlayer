2. Legal Basis:
The processing of data is based on Article 6(1)(f) GDPR (legitimate interest). Our legitimate interest lies in providing a stable and secure web-based radio player with a recording function directly within the browser.

3. Web Hosting & Data Collection:
This website is hosted via GitHub Pages (provided by GitHub, Inc., USA). To deliver static files and ensure server stability, server log files (such as IP address, browser type, date/time) are processed by GitHub. For details, see the GitHub Privacy Statement. In accordance with the provided MIT License, you are free to download the source code of this project and run it on your own web space or server. In the event of such self-hosting, the responsibility for data privacy compliance (including the logging of server log files by your respective web host) lies solely with you as the operator of that specific instance.

4. External Audio Streams:
This player does not host audio files. It establishes a direct client-side connection from your browser to external broadcast servers. Your IP address is transmitted to the streaming providers to deliver the audio stream, governed by their respective privacy terms.

5. Local Storage (IndexedDB):
For timeshift buffer features, audio chunks are stored exclusively on your device using the browser's IndexedDB. No audio data is uploaded to us or third-party servers. You can clear this cache anytime via your browser settings.

6. Cookies and Tracking:
This application does not use tracking cookies, tracking pixels, or third-party analytics tools.

7. User Rights & Security:
Under the GDPR, you have the right to request access to, rectification of, or erasure of personal data, as well as the right to lodge a complaint with a supervisory authority. All web connections are secured via SSL/TLS encryption.
